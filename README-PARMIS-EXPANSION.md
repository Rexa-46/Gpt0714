# Rexa 5.1.2 — Personal Finance Pro

این نسخه بر پایه Rexa فعلی توسعه داده شده و قابلیت‌های موجود را حذف نمی‌کند. ساختار جدید با الهام از امکانات رسمی پارمیس همراه طراحی شده، اما کد و رابط Rexa مستقل است.

## امکانات حفظ‌شده
- قفل PIN و احراز هویت بیومتریک واقعی در APK
- پشتیبان‌گیری و بازیابی JSON و پشتیبان هنگام خروج
- خواندن پیامک بانکی در APK و تشخیص تراکنش
- ثبت سریع با متن/صدا و موتور تشخیص مبلغ و دسته
- حساب‌ها، انتقال بین حساب‌های خودم، تراکنش‌ها و گزارش‌ها
- چک‌ها، وام و اقساط، بودجه، قبض‌ها، دارایی‌ها و تراکنش‌های تکرارشونده
- اشخاص، بدهکار/بستانکار، ارزها، اعضای خانواده، رویداد و پروژه
- خروجی Excel، نمودارها، تقویم شمسی، میانبرهای تراکنش و تنظیمات شخصی‌سازی

## توسعه جدید 5.1.2
- اهداف مالی و پس‌انداز با درصد پیشرفت
- ذخیره هدف‌ها در دیتای اصلی و پشتیبان‌ها
- نسخه‌گذاری فایل پشتیبان برای سازگاری بهتر نسخه‌های بعدی
- منوی یکپارچه برای دسترسی به ماژول‌های مالی

## اصل توسعه
هدف این نسخه این است که Rexa به یک دستیار مالی شخصی حرفه‌ای تبدیل شود؛ یعنی بخش‌ها فقط ظاهری نباشند و داده‌های آنها در گزارش، پشتیبان و داشبورد قابل استفاده باشند.
