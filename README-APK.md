# تبدیل «Rexa» به اپلیکیشن اندروید (APK)

## اول یک نکته‌ی مهم درباره‌ی گیت‌هاب شما
من هیچ دسترسی‌ای به حساب GitHub شما ندارم (نه توکن، نه اتصال) — پس نمی‌تونم ریپازیتوری‌تون رو پاک یا مدیریت کنم. ولی خودتون در ۳۰ ثانیه می‌تونید این کارو بکنید:

**برای پاک کردن ریپازیتوری قبلی:**
1. برو به صفحه‌ی همون ریپازیتوری در GitHub
2. **Settings** (تب بالای صفحه‌ی ریپو) → پایین صفحه بیا تا بخش قرمزرنگ **Danger Zone**
3. **Delete this repository** → اسم ریپو رو تایپ کن برای تایید → حذف می‌شه

بعدش می‌تونید یه ریپوی خالی و تازه بسازید و همین پوشه‌ی جدید رو توش push کنید (مراحلش پایین‌تر هست).

## چرا این نسخه فرق داره: مشکل شبکه‌ی محلی شما رو دور می‌زنیم
خطایی که قبلاً گرفتید (`Unknown host https://403.online`) از سمت اینترنت خود کامپیوترتون بود — چیزی (ISP، روتر، یا آنتی‌ویروس) داشت درخواست‌های Gradle رو ریدایرکت می‌کرد. این مشکل به پروژه ربطی نداره و هر چقدر هم تنظیمات پروژه رو عوض کنیم، دوباره برمی‌گرده چون منشأش بیرون از پروژه‌ست.

**راه‌حل واقعی: بذار GitHub خودش APK رو بسازه، نه کامپیوتر شما.** سرورهای GitHub یه اینترنت تمیز و مستقیم به Google/Gradle دارن، پس اون خطای DNS/پروکسی اونجا اصلاً پیش نمیاد. از این به بعد این روش رو به‌عنوان مسیر اصلی پیشنهاد می‌کنم؛ Android Studio روی کامپیوتر خودتون رو فقط برای تست/اجرا (اختیاری) نگه دارید.

من همچنین ورک‌فلوی GitHub Actions رو این‌بار طوری تنظیم کردم که دقیقاً با نسخه‌های نرم‌افزاری هماهنگ باشه که سرورهای خود GitHub از قبل دارن (چک کردم قبل از نوشتنش):
- روی Ubuntu 24.04 قفل شده (نه "latest" که ممکنه بی‌خبر عوض بشه)
- از JDK 21 که از قبل روی همون سرور نصبه استفاده می‌کنه (دانلود جداگونه لازم نیست)
- Android SDK (نسخه ۳۶، همونی که Capacitor 8 لازم داره) از قبل روی اون سرور نصبه
- یه مرحله‌ی امن هم اضافه کردم که اگه SDK لازم رو پیدا نکرد، خودش نصبش کنه
- کش کردن Gradle برای سرعت بیشتر در دفعات بعدی

## مراحل کامل (از صفر)

### ۱. ساخت ریپازیتوری تازه در GitHub
- برو github.com → دکمه‌ی سبز **New** → یه اسم بذار (مثلاً `rexa`) → **Create repository** (خالی، بدون README/gitignore)

### ۲. آماده‌سازی روی کامپیوتر
فایل `rexa-apk-scaffold.zip` رو دانلود و Extract کن، بعد داخل همون پوشه یه ترمینال باز کن.

### ۳. push کردن
```bash
git init
git add .
git commit -m "اولین نسخه Rexa"
git branch -M main
git remote add origin https://github.com/USERNAME/rexa.git
git push -u origin main
```
(به‌جای `USERNAME` اسم کاربری خودتو بذار)

### ۴. تماشای ساخته‌شدن خودکار APK
- برو به تب **Actions** در همون ریپو
- ورک‌فلوی «Build Android APK» خودش شروع می‌شه (چون فایلش از قبل توی `.github/workflows/build-apk.yml` هست)
- صبر کن تا علامت ✅ سبز بیاد (معمولاً ۵ تا ۱۰ دقیقه)

### ۵. دانلود APK
- روی همون اجرا کلیک کن → پایین صفحه بخش **Artifacts** → فایل `rexa-debug-apk` رو دانلود کن (یک zip کوچیک، داخلش `app-debug.apk` هست)

### ۶. نصب روی گوشی
فایل apk رو به گوشی منتقل کن، «نصب از منابع ناشناس» رو در تنظیمات گوشی فعال کن، و نصبش کن.

## اگه باز هم در تب Actions خطا گرفتی
این‌بار خطا دیگه نباید به دلیل شبکه یا نسخه باشه (چون از سرور تمیز GitHub استفاده می‌کنیم و نسخه‌ها از قبل چک شدن). اگه بازم خطا اومد:
1. روی همون run قرمز کلیک کن
2. روی step ای که ❌ خورده کلیک کن تا لاگ کامل باز بشه
3. کل متن قرمز رنگ رو کپی کن و برام بفرست — این لاگ خیلی دقیق‌تر و قابل‌اعتمادتر از خطاهای محلی روی ویندوزته چون هیچ عامل بیرونی (VPN، آنتی‌ویروس، DNS) روش تاثیر نمی‌ذاره.

## اجرای محلی (اختیاری، فقط اگه Android Studio باز هم خواستی امتحان کنی)
راهنمای جدا داری در `README-ANDROID-STUDIO.md` — ولی توصیه می‌کنم فعلاً روی روش GitHub Actions بالا تمرکز کنی چون قابل‌اعتمادتره.

## ساخت نسخه‌ی نهایی امضاشده برای انتشار در Google Play (اختیاری، بعداً)
انتشار در Google Play نیاز به یک "keystore" امضا داره که باید خودتون بسازید و امن نگه دارید (هرگز داخل ریپازیتوری عمومی قرار ندید). وقتی به این مرحله رسیدی، بگو تا ورک‌فلوی GitHub Actions رو برای build امضاشده (release) هم تکمیل کنم.

## نکات مهم درباره‌ی کد
- `src/App.jsx` همون اپلیکیشنیه که در Claude.ai دیدید — هیچ تغییری در منطق یا ظاهر برنامه داده نشده.
- ذخیره‌سازی داده‌ها خودکار تشخیص می‌ده که در Claude.ai اجرا می‌شه (از `window.storage` استفاده می‌کنه) یا مستقل/APK اجرا می‌شه (از `localStorage` گوشی استفاده می‌کنه).
- پوشه‌ی `android/` عمداً در ریپازیتوری کامیت نمی‌شه (داخل `.gitignore` هست) — هر بار که Actions اجرا می‌شه، این پوشه از نو با `npx cap add android` ساخته می‌شه، پس همیشه با نسخه‌ی Capacitor داخل `package.json` هماهنگه و هیچ فایل قدیمی/ناسازگاری باقی نمی‌مونه.
