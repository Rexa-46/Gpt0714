# Third-party notices

Rexa uses `@capacitor-community/sqlite` with SQLCipher for encrypted native SQLite storage.

The SQLite plugin documents that native encrypted databases use SQLCipher and that SQLCipher's Community Edition license/copyright notice must be made available to users when that edition is bundled. Before production distribution, include the applicable SQLCipher license text in Rexa's About / Licenses screen and review export/compliance requirements.

Reference: https://github.com/capacitor-community/sqlite/blob/master/docs/DatabaseEncryption.md
